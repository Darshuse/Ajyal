# أجيال

لعبة المجلس العربية بين الأجيال — فريقان على جهاز واحد، أسئلة بمستويات، ونظام موازنة يبقي الحماس.

## التشغيل محليًا
```bash
npm start
```
ثم افتح `http://localhost:3000`.

## النشر (Railway)
- Railway يكتشف Node تلقائيًا عبر `package.json` ويشغّل `npm start`.
- الخادم يقرأ المنفذ من `process.env.PORT`.

## ملاحظة
اللعبة ملف واحد (`index.html`) يعمل دون إنترنت. ميزات «بنك المجتمع المشترك» وتسجيل التغذية الراجعة تعمل فقط داخل بيئة claude.ai artifacts؛ خارجها ترجع تلقائيًا للتخزين المحلي.
